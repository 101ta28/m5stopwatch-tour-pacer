# コース設定と記録の見方

初期コースは導入2分、展示説明7分、体験4分、移動2分です。振動の予告は、案内の終了2分前と区間の目安30秒前に設定されています。終了日時と持ち時間は、どちらも本体の待機画面またはUSBで指定できます。

## 持ち時間を決めて発表する

待機画面で「持ち時間」をタップし、「分」または「秒」を選び、＋・−で調整して「確定」を押します。最初はコースの標準時間の合計が表示されます。発表を始めるときに「計時を開始」をタップするか、Aを0.8秒長押ししてください。開始を待つ間は時間が減らず、本体の時計が未設定でも使えます。

持ち時間を使い切ると振動し、その後は超過時間が表示されます。Aを0.8秒長押しして終了すると、持ち時間と実際の所要時間を比較できます。質問の記録には、発表の開始から何分何秒で質問があったかが表示されます。同じ持ち時間で繰り返し練習できます。待機画面の「終了日時」から日時指定に切り替えられます。

## USBでJSONファイルから設定する

1. 現在のコースで持ち時間だけを15分にするには、`{"durationSeconds": 900}` をUTF-8のJSONファイルに保存します。コースも指定したい場合は、[施設案内の例](../examples/course.json)か[発表12分・質疑応答3分の例](../examples/presentation.json)をコピーしてください。`name` はコース名、`segments` は区間の一覧で、各区間の `seconds` に標準秒数を指定します。`warnings.overall` と `warnings.segment` は、全体と各区間で何秒前に振動するかを表します。
2. コースのJSONにも、持ち時間を秒単位で指定する `durationSeconds` を追加できます。終了日時を指定する場合は `"deadline": "2026-12-01T14:15"` のように現地日時を指定してください。一つのファイルに指定できるのはどちらか一方です。両方省略すると、コースと振動予告だけを変更し、本体で選んだ終了条件を引き継ぎます。
3. この機能を含む[ファームウェアを書き込み](setup.md)、本体を待機画面にしてPCにUSB接続します。リポジトリのルートで次のコマンドを実行してください。ポート名とファイル名は手元のものに置き換えます。

   | OS | コマンド例 |
   |---|---|
   | Windows | `py -3 scripts/sync-course.py COM3 course.json` |
   | macOS | `python3 scripts/sync-course.py /dev/cu.usbmodem101 course.json` |
   | Linux | `python3 scripts/sync-course.py /dev/ttyACM0 course.json` |

4. 設定完了の表示が出たら本体の待機画面で値を確認し、発表なら「計時を開始」、終了日時を指定した案内なら「案内を開始」をタップします。

コースと振動予告は電源を切っても残ります。終了日時は案内のたびに確定します。持ち時間は次の発表にも使えますが、再起動後はもう一度指定してください。

`deadline` を指定するには、本体の時計が設定済みで、終了日時が本体の現在日時より後であることが必要です。この条件を満たさない場合はエラーになり、以前のコースと終了日時が保たれます。

## Wi-Fiでコースを変更する

1. StopWatchの待機画面で「コース配分」→「Wi-Fiで設定」をタップします。
2. スマートフォンまたはPCを、本体に表示されたWi-Fi（`M5StopWatch-xxxx`）に接続します。パスワードは同じ画面にある8桁の数字です。「インターネット接続なし」と表示されても接続を続けてください。
3. ブラウザーで本体に表示されたURL（通常は `http://192.168.4.1`）を開きます。コース名、区間の名前・順番・目安時間、振動予告を編集できます。時間は分と秒で入力でき、片方だけでも指定できます。
4. ブラウザーで「本体に保存」を押します。「本体に保存しました」と表示されたら、StopWatchで「Wi-Fiを終了」をタップし、新しい配分を確認します。設定は電源を切っても残ります。

区間は1〜32個で、各区間の目安は1秒以上です。コース名と区間名はそれぞれUTF-8で96バイトまでです。

## 案内の開始と計時

翌日に終わる案内では、終了時刻を設定するときに日付も変更します。終了日時を確定すると、画面の「案内を開始」のほか、Aの0.8秒長押しでも始められます。

案内開始時と「次の区間」に進んだときに、終了までの残り時間を、これから案内する区間の標準時間に比例して配分します。たとえば15分の初期コースで、導入に3分かかったときは展示説明に6分28秒、導入を1分で終えたときは7分32秒を割り当てます。最後の区間では、終了までの残り時間をすべて使えます。

外側のリングは案内全体の残り時間を示します。内側は12時の位置から時計回りに区間が並びます。現在の区間を示す黄緑の弧は、「今回の目安」に表示される残り時間に合わせて短くなります。持ち時間を過ぎると濃い緑の弧が区間の位置を示し、「目安超過」に超過時間が表示されます。終了時刻以降に次の区間に進んだ場合、その区間の持ち時間はゼロです。区間が一つのコースでは内側のリングを省きます。

**黄緑の残り時間がゼロになると、短く3回振動します。** この合図は各区間で一度だけです。案内全体の予告や終了時刻の振動と重なる場合は、全体の合図を優先します。区間を進めるときは、Aを短押しするか「次の区間」をタップしてください。

30秒操作しないと画面が暗くなります。計時と振動は続き、最初のタップやボタン操作もそのまま受け付けます。

質問は案内1回につき1,024件まで記録できます。それを超えて記録しようとすると画面に通知が出ます。計時と案内の終了操作は続けられます。

## 終了後に記録を見る

案内を終えると、全体の所要時間と予定よりどれだけ早く、または遅く終えたかが表示されます。「次の区間」またはAで、区間ごとの実績と質問があった時刻を確認できます。実績との差は、コースに設定した標準時間を基準にしています。質問が4件以上ある区間では、一覧を上下にスワイプしてください。

「待機に戻る」またはBで待機画面に戻ります。直近1回の結果は、待機画面の「保存記録」から開けます。

**「再保存」が表示されたら、電源を切る前にタップしてください。** 保存に成功するまでは今回の結果を画面に保持します。先に電源を切ると今回の結果は失われますが、直前に保存できた記録は残ります。
